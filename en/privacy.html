Privacy Policy

This page explains how the Wang QP Lab website (WangQPLab) collects and uses information.

Information Collection

This is a purely static website. It has no user accounts, collects no personal information and uses no tracking cookies. Basic access records (IP address, browser type, access time) are retained only in server access logs for site operation and security maintenance, and are never shared or sold.

Third-Party Services

  • This site uses static-resource CDNs such as Font Awesome / tippy.js / mark.js; visiting the site may generate routine CDN request logs. Please refer to the privacy policies of the respective providers.
  • External websites linked from this site (e.g. journal websites and academic databases) are governed by their own privacy policies, which are not covered by this page.

Contact

If you have any questions about this privacy policy, please contact us through the email address provided on this site.
