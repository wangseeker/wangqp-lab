# {% include icon.html icon="fa-solid fa-microscope" %}研究方向

本课题组以果蝇为模式生物结合小鼠模型，围绕**能量代谢调控**与**衰老机制**两大主线，构建"机制解析—靶点发现—转化应用"三位一体的研究体系：

- **肥胖研究**：全基因组筛选鉴定能量代谢调控基因（MTCH2、NMI、TRPC6、SEC16B 等），揭示甜味味觉与营养感知的神经机制，开发天然化合物与联合用药干预策略
- **衰老研究**：研发果蝇寿命实验系统与 NAD 通路抗衰老药物，解析 mTORC1 与神经元衰老的调控机制

{% include section.html %}

## 肥胖研究

肥胖是高血压、心血管疾病及2型糖尿病的主要风险因素。课题组以果蝇为模式生物，通过全基因组功能性筛选鉴定新的能量代谢调控基因，并利用基因敲除小鼠验证其在哺乳动物中的功能，致力于发现新的减肥药物靶点；同时研究甜味味觉调控与能量代谢的关系。
