# {% include icon.html icon="fa-solid fa-dna" %}肥胖研究

肥胖已成为全球普遍现象，是高血压、心血管疾病及2型糖尿病的主要风险因素。尽管已为肥胖治疗付出巨大努力，但市场上有效的肥胖治疗药物依然匮乏。课题组以果蝇为模式生物结合小鼠模型，围绕**能量代谢调控**这一核心科学问题，从"基因发现—机制解析—转化应用"三个层次系统性推进肥胖研究。

{% include section.html %}

## 能量代谢调控基因的发现与功能验证

**策略**：以果蝇为模式生物进行全基因组功能性筛选（神经组织特异性 RNAi 基因沉默），筛选与人类代谢和肥胖相关的基因，再利用基因敲除小鼠验证其在哺乳动物中的功能，最终发现新的减肥药物靶点。

**关键发现**：

- **MTCH2 调控脂肪产热**：MTCH2 通过抑制自噬阻碍脂肪产热——揭示肥胖新机制，为棕色/米色脂肪产热调控提供新靶点（*Advanced Science* 2025）
- **NMI 促进肥胖**：NMI 通过 TLR4/IRF3 信号调控脂肪适应性产热，促进肥胖发生（*Advanced Science* 2026）
- **TRPC6 与棕色脂肪**：TRPC6 经 BMPR2-p38 MAPK 信号轴调控棕色脂肪产热（*Theranostics*）
- **NKX6.3 与减重**：大规模减重干预人群的基因水平分析发现 NKX6.3 在代谢中的潜在作用（*Nature Communications* 2019，共同一作）
- **SEC16B 调控血糖稳态**：发现 SEC16B 是调控血糖的关键基因，为糖尿病机制研究提供新视角（*Diabetologia* 2025）
- **dSec16 控制能量稳态**：果蝇 dSec16 在胰岛素样肽产生细胞中调控能量稳态（2025）
- **"瘦"基因 ALK**：参与发现 ALK 调控交感神经抵抗体重增加（*Cell* 2020）

## 甜味味觉与营养感知

甜味感觉影响食物摄取，甜味味觉失调可导致肥胖或厌食。课题组揭示**甜味—能量双向调控机制**，破解代糖争议与代谢失衡矛盾：

- **代糖与食欲**：Sucralose 通过 NPY 和神经元"禁食反应"促进食物摄入（*Cell Metabolism* 2016）；慢性 Sucralose 或 L-葡萄糖摄入不抑制进食（*Cell Metabolism* 2017）
- **高糖重塑甜味**：高糖饮食重塑甜味感知，促进进食行为（*Cell Reports* 2020）
- **谷氨酰胺—肠脑轴**：谷氨酰胺通过肠道菌群—肠—脑轴增强果蝇甜味感知
- **营养几何框架**：利用营养几何理论解析蛋白质—碳水化合物平衡对甜味敏感性（*JGG* 2023）、睡眠（*Nutr Metab* 2019 合作）的影响
- **分子机制**：PGC1α、AMPK 调控蔗糖甜味敏化的神经分子机制（*Cell Reports* 2020；*JGG* 2022）
